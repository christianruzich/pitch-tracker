Pitches thrown per pitcher, per day, over a recent window. Data pulled live from MLB's public Stats API.

Source: MLB Stats API (statsapi.mlb.com), fetched directly by your browser — no server involved. "Yesterday" and the date window are based on your device's local clock. Doubleheader games on the same date are summed into that date's cell; if either game was a start, the cell is marked as a start. An asterisk (*) after a pitcher's name means left-handed. A white outline around a count marks a start; starts over 60 pitches have no color fill. A blue band marks consecutive days of pitching (hover for the run length).
